# Changelog

## [1.0.1] — 2026-10-09

### ✨ Added
- 🎨 New DropSort application icon for Windows and macOS.
- 🍎 macOS `.dmg` installer with Applications shortcut.
- 🪟 Windows `DropSort-Setup.exe` installer.
- 🧰 Automated installer builds through GitHub Actions.

### 🛠️ Improved
- 📦 Release builds now ship as proper installers instead of only ZIP archives.
- 🖥️ Application metadata now uses the DropSort bundle identifier on macOS.

### 🐛 Fixed
- 🐍 Removed the default PyInstaller icon from packaged builds.

## [1.0.0] — 2026-10-08

- 🚀 Initial public release.
- 📁 Automatic file categorization.
- 📱 iPhone / Android photo and video format support.
- 🛡️ Duplicate-safe file moving.
- 🖥️ macOS and Windows builds.
